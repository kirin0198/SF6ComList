# ISSUE-001: コンボ登録画面にコマンドリスト入力モードを追加

> 作成日: 2026-04-12
> Issue種別: 機能追加
> ステータス: 分析完了・承認済み

## 概要

コンボ登録画面（SCR-005）/ 編集画面（SCR-007）の入力モードに「コマンドリスト」タブを追加する。
キャラクター固有のコマンドリスト（必殺技・特殊技・ターゲットコンボ等）から技を選択してコンボを組み立てるモード。

ユーザーフィードバック: コマンドリストをデフォルトタブとする。

## 分析結果

### 現状

- 現在の入力モードは「ビジュアル入力」と「テキスト入力」の2タブ構成
- `ComboForm.tsx` の `InputMode` 型は `"visual" | "text"` の2種
- デフォルトは `"visual"` に設定されている（`useState<InputMode>("visual")`）
- キャラクター固有のコマンドリストデータは存在しない
- `src/data/characters.json` にはキャラクターの基本情報のみ（id, name, displayName, status）

### 必要な変更

1. **キャラクター別コマンドリストデータの設計・作成**
   - 各キャラクターの必殺技・特殊技・ターゲットコンボ・SA等をJSONマスタデータとして定義
   - テンキー表記コマンド + 技名 + カテゴリを含む構造
   - 初期データとしてリュウのコマンドリストを作成（他キャラは段階的に追加）

2. **コマンドリスト入力コンポーネントの新規作成**
   - カテゴリ別に技を一覧表示するパネル
   - 技をクリックすると対応する `ComboStep[]` がシーケンスに追加される
   - コネクター自動挿入（既にステップがある場合は `>` を自動追加）

3. **ComboForm の3タブ化**
   - `InputMode` 型に `"commandList"` を追加
   - タブ順序: コマンドリスト / ビジュアル入力 / テキスト入力
   - デフォルトタブ: コマンドリスト
   - 3タブ間のデータ相互変換を維持

4. **SPEC.md に UC-013 を追加**
5. **UI_SPEC.md に SCR-005 のコマンドリスト入力パネルレイアウトを追記**

## 対応方針

### データ構造設計

```typescript
interface CommandMove {
  id: string; // 一意ID
  name: string; // 技名（日本語）
  nameEn: string; // 技名（英語）
  category: CommandCategory; // カテゴリ
  notation: string; // テンキー表記（例: "236HP"）
  steps: ComboStep[]; // パース済みステップ
}

type CommandCategory =
  | "normal" // 通常技（立ち/しゃがみ）
  | "unique" // 特殊技（固有技）
  | "special" // 必殺技
  | "super" // スーパーアーツ
  | "target-combo" // ターゲットコンボ
  | "throw" // 投げ
  | "drive"; // ドライブ系システム技
```

### コマンドリストデータ格納

- `src/data/command-lists/{characterId}.json` にキャラクター別JSONファイルとして配置
- 初期はリュウ（ryu.json）を作成、他キャラクターは空の状態を許容する
- 将来的に全キャラクター分を段階的に追加

### コンポーネント設計

- `src/components/input/CommandListPanel.tsx` を新規作成
- カテゴリ別アコーディオン or セクション表示
- 各技の行: 技名 + テンキー表記 + ワンクリック追加ボタン
- 検索/フィルタ機能は Phase 2 とする
