## 1. デザイン方針

### トーン & マナー

SF6 のビジュアルアイデンティティである**ストリートアート / グラフィティ文化**をモチーフにしつつ、コンボの記録・参照という**実用性**を最優先にしたダークテーマのUI。

- **ダークベース:** ゲーム中のトレーニングモードのようなダーク背景で視認性を確保する
- **鮮やかなアクセント:** SF6 のネオンカラー（シアン、マゼンタ、イエロー）をアクセントに使用する
- **情報密度:** 格ゲープレイヤーは情報の密度に慣れているため、コンパクトに詰め込む方向
- **コントラスト:** ダーク背景に対して、ボタンの色分けが明確に区別できるコントラスト比を確保する

### コンポーネントライブラリ

- **ベース:** Tailwind CSS v3 のユーティリティクラスで構築する（UIライブラリは使用しない）
- **グリッドシステム:** 8px グリッドベース（Tailwind のスペーシングスケール: 1unit = 4px）
- **角丸:** コンポーネントは `rounded-lg` (8px)、ボタンは `rounded` (4px)、バッジは `rounded-full`
- **影:** 使用しない（ダークテーマではボーダーで区切りを表現する）
- **ボーダー:** `border border-gray-700` を基本とする
- **トランジション:** `transition-colors duration-150` を全インタラクティブ要素に適用する

### アイコン

- **方向キー:** 自作 SVG コンポーネント（矢印アイコン、24x24px）。フォールバックとして Unicode 矢印文字（PoC で使用）
- **ボタン:** 円形背景 + テキストラベル（LP, MP, HP 等）で表現する自作 SVG コンポーネント
- **UIアイコン:** Lucide React（MIT ライセンス）を使用する
  - 編集: `Pencil`、削除: `Trash2`、戻る: `ArrowLeft`、追加: `Plus`、検索: `Search`
  - ログアウト: `LogOut`、ユーザー: `User`、チェック: `Check`
- **クレジット:** Fighting Game Input Icons Pack (CC-BY-4.0) をベースにする場合はフッターにクレジット表記する

## 4. 画面詳細

### SCR-001: ログイン画面

**目的:** 登録済みユーザーがメール/パスワードでログインする
**対応UC:** UC-002
**遷移元:** SCR-002（登録画面のログインリンク）、ログアウト操作
**遷移先:** SCR-003（ログイン成功時）、SCR-002（登録リンクのクリック）
**URL パス:** `/login`

#### レイアウト構成

```
+----------------------------------------------------------+
|                                                          |
|              SF6 コンボ帳                                 |
|              (ロゴ / タイトル)                             |
|                                                          |
|          +----------------------------------+            |
|          |                                  |            |
|          |  メールアドレス                    |            |
|          |  [________________________]       |            |
|          |                                  |            |
|          |  パスワード                        |            |
|          |  [________________________] [👁]  |            |
|          |                                  |            |
|          |  [      ログイン      ]           |            |
|          |                                  |            |
|          |  アカウントをお持ちでない方は       |            |
|          |  新規登録はこちら                   |            |
|          |                                  |            |
|          +----------------------------------+            |
|                                                          |
+----------------------------------------------------------+
```

#### コンポーネント詳細

| #   | コンポーネント     | 種別                 | 状態                                          | 説明                                                                                                                                    |
| --- | ------------------ | -------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | ロゴ/タイトル      | Text                 | static                                        | 「SF6 コンボ帳」のタイトル。`text-2xl font-bold text-white` + SF6風のアクセント色サブタイトル                                           |
| 2   | メールアドレス入力 | Input[type=email]    | default / focus / error                       | `w-full bg-gray-800 border border-gray-700 rounded text-white px-3 py-2 text-sm focus:border-cyan-500 focus:ring-1 focus:ring-cyan-500` |
| 3   | パスワード入力     | Input[type=password] | default / focus / error                       | メールアドレスと同じスタイル。右端にパスワード表示/非表示トグルボタン                                                                   |
| 4   | ログインボタン     | Button (primary)     | default / hover / active / disabled / loading | `w-full bg-cyan-600 hover:bg-cyan-500 active:bg-cyan-700 disabled:opacity-40 text-white font-bold py-2 rounded transition-colors`       |
| 5   | 登録リンク         | Link                 | default / hover                               | `text-cyan-400 hover:text-cyan-300 text-sm underline`                                                                                   |
| 6   | エラーメッセージ   | Alert                | hidden / visible                              | `bg-red-900/50 border border-red-700 text-red-300 text-sm px-3 py-2 rounded`                                                            |

#### インタラクション

| トリガー                     | アクション                            | フィードバック                                                                                         |
| ---------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| ログインボタンクリック       | API にメール/パスワードを送信         | ボタンが loading 状態（スピナー表示）に変わる。成功時は SCR-003 へ遷移。失敗時はエラーメッセージを表示 |
| Enter キー押下               | ログインボタンと同じアクション        | 同上                                                                                                   |
| 新規登録リンククリック       | SCR-002 へ遷移                        | ページ遷移                                                                                             |
| パスワード表示トグルクリック | type=password と type=text を切り替え | アイコンが目/目スラッシュに切り替わる                                                                  |

#### バリデーション

| フィールド     | ルール            | エラーメッセージ                                                                  |
| -------------- | ----------------- | --------------------------------------------------------------------------------- |
| メールアドレス | 必須 / メール形式 | 「メールアドレスを入力してください」 / 「有効なメールアドレスを入力してください」 |
| パスワード     | 必須              | 「パスワードを入力してください」                                                  |
| 認証結果       | サーバー側検証    | 「メールアドレスまたはパスワードが正しくありません」                              |

#### 状態パターン

| 状態                 | 条件                    | 表示内容                                                             |
| -------------------- | ----------------------- | -------------------------------------------------------------------- |
| 通常                 | 初期表示                | 空のフォームとログインボタン                                         |
| ローディング         | ログインAPIリクエスト中 | ボタンにスピナー表示、ボタン disabled                                |
| エラー               | 認証失敗                | フォーム上部にエラーメッセージバナー                                 |
| バリデーションエラー | 入力値不正              | 各フィールド下部に赤文字でエラーメッセージ、フィールドボーダーが赤に |

## 7. アクセシビリティ要件

WCAG 2.1 AA 準拠を目標とする。

### 基本要件

| 項目                     | 対応方針                                                                                                                                           |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| カラーコントラスト       | ダーク背景 (#171717) に対してテキストは最低 4.5:1 のコントラスト比を確保する。白テキスト (#ffffff) = 15.4:1、gray-400 (#9ca3af) = 4.6:1 で AA 準拠 |
| キーボード操作           | 全てのインタラクティブ要素が Tab キーでフォーカス可能であること。方向キーパッドは矢印キーでも操作可能にする                                        |
| フォーカスインジケーター | `focus-visible:ring-2 focus-visible:ring-cyan-500 focus-visible:ring-offset-2 focus-visible:ring-offset-gray-900`                                  |
| aria-label               | 方向キーパッドの各ボタンに方向名ラベル（「上」「下前」等）、ボタンパレットの各ボタンに技名ラベル（「弱パンチ」「ドライブラッシュ」等）             |
| フォームラベル           | 全入力フィールドに `<label>` を紐付ける                                                                                                            |
| エラーメッセージ         | `aria-live="polite"` + `role="alert"` でスクリーンリーダーに通知する                                                                               |
| 色に依存しない情報伝達   | ボタンの色分けだけでなく、テキストラベル（LP, MP, HP 等）でも区別できるようにする                                                                  |

### 方向キーパッドのキーボード操作

```
Tab でパッド全体にフォーカス → 矢印キーで方向ボタン間を移動 → Enter/Space で方向を選択
```

- `role="grid"` + `role="row"` + `role="gridcell"` で構造化する
- `aria-label="方向キーパッド"` をグリッドに設定する

### ボタンパレットのキーボード操作

```
Tab でグループにフォーカス → 左右矢印キーでボタン間を移動 → Enter/Space で選択
```

- 各グループに `role="group"` + `aria-label` を設定する

## 8. アニメーション・トランジション

### 基本方針

- パフォーマンス優先。GPU アクセラレーションが効く `transform` / `opacity` のみ使用する
- 過度なアニメーションは避け、操作のフィードバックに限定する
- `prefers-reduced-motion` メディアクエリでアニメーションの無効化をサポートする

### トランジション一覧

| 要素                 | トリガー              | プロパティ                            | 値                                        | Tailwind                                |
| -------------------- | --------------------- | ------------------------------------- | ----------------------------------------- | --------------------------------------- |
| ボタン（全般）       | hover / active        | background-color                      | 150ms ease                                | `transition-colors duration-150`        |
| カード               | hover                 | border-color, background-color        | 150ms ease                                | `transition-colors duration-150`        |
| タグバッジ           | クリック（選択/解除） | background-color, border-color, color | 150ms ease                                | `transition-colors duration-150`        |
| モーダルオーバーレイ | 表示 / 非表示         | opacity                               | 200ms ease-out                            | `transition-opacity duration-200`       |
| モーダル本体         | 表示                  | opacity, transform (scale)            | 200ms ease-out (in) / 150ms ease-in (out) | カスタムアニメーション                  |
| トースト             | 表示                  | transform (translateX)                | 300ms ease-out                            | `animate-slide-in-right`                |
| トースト             | 非表示                | opacity                               | 300ms ease-in                             | `animate-fade-out`                      |
| ページ遷移           | ルート変更            | なし                                  | Next.js デフォルト                        | アニメーションなし（MVPではシンプルに） |

### カスタムアニメーション定義（tailwind.config.js）

```javascript
// tailwind.config.js の extend.keyframes / extend.animation に追加
keyframes: {
  'slide-in-right': {
    '0%': { transform: 'translateX(100%)', opacity: '0' },
    '100%': { transform: 'translateX(0)', opacity: '1' },
  },
  'fade-out': {
    '0%': { opacity: '1' },
    '100%': { opacity: '0' },
  },
  'scale-in': {
    '0%': { transform: 'scale(0.95)', opacity: '0' },
    '100%': { transform: 'scale(1)', opacity: '1' },
  },
},
animation: {
  'slide-in-right': 'slide-in-right 300ms ease-out',
  'fade-out': 'fade-out 300ms ease-in',
  'scale-in': 'scale-in 200ms ease-out',
},
```

### 9.2 ドラフト状態管理

コンボ入力は「ドラフト」と「コミット済み」の2層で状態管理する。

```
State = {
  committedSteps: ComboStep[]   // 確定済みステップの配列
  draft: {
    directions: Direction[]     // 選択中の方向 (例: ["2","3","6"])
    isOD: boolean               // ODトグルの状態
  }
}
```

**状態遷移:**

1. 方向クリック: `draft.directions` に方向を追加
2. ボタンクリック: `committedSteps` に NormalInput を追加、`draft` をリセット
3. コネクタークリック: `committedSteps` に ConnectorStep を追加
4. 元に戻す: `draft.directions` が空でなければ最後の方向を削除、空なら `committedSteps` の最後を削除
5. リセット: 全状態をクリア

### 9.3 テキスト入力モードとの相互変換

```
[ビジュアルモード]                    [テキストモード]
  committedSteps ───serializeNotation()──> テキストフィールド
  committedSteps <──parseNotation()────── テキストフィールド
```

- モード切替時: 現在の入力内容を変換して反対側のモードに反映する
- テキスト入力はデバウンスを適用する（300ms）。入力のたびにパースを実行すると重いため
- パースエラー: テキストフィールド下部に `text-yellow-300 text-xs` でエラー箇所を表示。プレビューはパース可能な部分のみ表示

## 10. SVG アイコン設計方針

### 方向アイコン

- ベース: 24x24px SVG
- 背景: 円形（`fill: #374151` / `gray-700`）
- 矢印: 白ストローク（`stroke: #ffffff`, `stroke-width: 2`）
- 5(ニュートラル): 中央に小さな丸点（`fill: #ffffff`）
- フォールバック: Unicode 矢印文字（PoC と同一）

### ボタンアイコン

- ベース: 32x24px SVG（横長の角丸長方形）
- 背景: グループ固有の色（カラーパレット参照）
- テキスト: 白太字の略称（「LP」「MP」等）
- ボーダー: `stroke: rgba(255,255,255,0.2)`, `stroke-width: 1`

### コネクターアイコン

- テキストベース表示（SVG不要）
- `font-mono font-bold text-yellow-300`
